# Agenda 2012 — GitHub Pages package

Production-ready static landing page for **Agenda 2012 — Artist's Book**.

## Upload to GitHub
Upload the **contents of this folder** to the repository root so that `index.html` is at the top level.

Required files:
- `index.html`
- `styles.css`
- `script.js`
- `assets/Baner.jpg`
- `assets/Carrousel_1.jpg` … `assets/Carrousel_5.jpg`
- `assets/instagram-icon.png`

## Embedded video
The video is embedded directly in the landing page in its own horizontal 16:9 section before the image carousel:
`https://www.youtube-nocookie.com/embed/gMKCYdDSccA`

## Acquisition
The **Adquirir** button opens Stripe in a new browser tab.

## Typography
CSS requests Futura PT first, with Book/Medium/Demi weight mapping (400/500/600). Font files are not included.
